Receives PagerDuty v3 triggered/reopened events on the external-ID webhook route. Simulation rejects live webhook intake. Live requires the configured authenticated signature-verifier connector, an allowed service and valid event fields. Saves the unique delivery and incident atomically, then returns 202 with an item ID and links to Fetch context. Duplicate events return 200 without a downstream item ID. No PagerDuty mutation occurs.
