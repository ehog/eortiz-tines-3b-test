Triggered by accepted intake or manual replay. Parses JSON or an HTTP response body containing itemId; other inputs are ignored. Reads the persisted item and, in live mode, GETs PagerDuty incidents/{id}, incidents/{id}/alerts and services/{id}. Requires a read-only PagerDuty connector in live mode. Bounded context is redacted and persisted as provenance. Incomplete, failed or oversized context becomes explicit investigation failure rather than benign evidence. Simulation uses fixtures without API calls. Output feeds the agent.
