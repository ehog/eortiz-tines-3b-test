Part of GHAWA, a read-only GitHub Actions security analyzer. See the [workflow setup and runbook](../README.md).

Triggered by deterministic review JSON or its own `agent-run` continuation. Has no HTTP route. Self-loops only while status is `running`; fixture, skipped, disabled, done and error paths terminate. Fixture mode is explicitly simulated. Live mode uses an Anthropic connector and GitHub read connector, with `claude-opus-5-5`, eight turns, a 60k token budget and sixteen serial content reads. Tool scope and budget are enforced outside the model. Read files are inert untrusted text. Context and transcript writes use per-review paths; transcript volume is `ghawa-conversations`. Finalize report handles terminal results and appends the decision audit. Do not remove the self-loop.
