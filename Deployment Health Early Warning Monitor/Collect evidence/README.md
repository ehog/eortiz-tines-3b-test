Triggered by Start assessment. Accept a job object or its HTTP 202 response body. Fixtures produce deterministic, clearly synthetic data; live.ts validates the selected Port blueprint, retrieves recent deployment/service metadata, queries New Relic NerdGraph and runs bounded Splunk search exports. Only read-only source operations. Attach the three read-only connectors here when enabling live. Each source degrades independently; errors, pagination/response caps and missing mappings are explicit. Redact before stdout or persistence. No arbitrary query input. Source request retries are bounded to three attempts and a 210-second collection deadline. Output is the job plus normalized windows, metrics, log signatures, source status and coverage warnings.
