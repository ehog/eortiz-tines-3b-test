Shared responder for both API routes (`output = true`). Reads `catalog.json` read-only from the `kev` volume, falling back to the live CISA feed if there's no snapshot yet. Returns filtered entries for `kind = "catalog"` or rollups for `kind = "metrics"`: totals, top vendors and products, and additions by month. Rollups count only KEV entries; `totals.watchlist` counts the NVD watchlist. Rejects anything other than GET with 405.
