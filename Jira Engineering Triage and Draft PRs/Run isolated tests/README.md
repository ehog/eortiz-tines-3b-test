Consumes stage=test. Executes baseline and patched inspected dependency-free Bun tests in America/Los_Angeles and UTC. Each command has a six-second limit and bounded output. Clean child environment, no package installation, no connectors, no volumes. Source files are ephemeral. External repository code runs only after configured demo authorization and Actions-disabled verification; otherwise status is not run. Tests are explicitly passed, failed or not run with exact command, exit status and captured output. Network isolation is not asserted; never use a repository with production credentials or privileged CI. Output goes to Publish draft PR.
