Consumes stage=test. Executes baseline and patched inspected dependency-free Bun tests in America/Los_Angeles and UTC. Each command has a six-second limit and bounded output. Clean child environment, no package installation, no connectors, no volumes. Each of the four invocations gets a newly materialized inspected snapshot and separate HOME and TMPDIR directories. Only patched invocations receive the proposed replacements; files created or modified by one invocation are discarded before the next. Temporary directories are removed in a finally block, including failed runs. Input paths must be relative, with no empty or dot-prefixed segments, and patches must replace inspected files. This prevents incidental filesystem contamination; it is not a security boundary against deliberately hostile code accessing other sandbox paths. External repository code runs only after configured demo authorization and Actions-disabled verification; otherwise status is not run. Tests are explicitly passed, failed or not run with exact command, exit status and captured output. Network isolation is not asserted; never use a repository with production credentials or privileged CI. Output goes to Publish draft PR.
