Shared intake for Jira webhooks, poll batches, and synthetic replays. Parses HTTP or JSON envelopes, validates project/label, fetches description, explicit acceptance criteria, recent comments and linked issues with the Jira connector. Bounds incomplete evidence and sends it to review. Exclusive state reservation deduplicates Jira keys and fixture replay IDs. Emits one ticket and remaining queue; self-link drains the queue while Triage receives the current ticket. Terminal errors go to Report outcome; terminal self-links stop when the queue is empty. settings.json is canonical; synchronize it with sync-config.sh. Fixtures are clearly labeled in fixtures.json.
