Consumes terminal agent-run output and loads trusted job/tool context from read-only volumes. Rejects unsafe paths, oversized changes, existing-test edits, missing test evidence, and obvious network/runtime capabilities. This is defense-in-depth rather than proof of safe arbitrary code. Emits stage=test with inspected source and replacements, or terminal human-review/failure evidence. Diff is generated from inspected originals. No external connector or code execution.
